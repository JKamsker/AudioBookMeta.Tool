# abs-audioknihi

Repository: `https://github.com/DeXP/abs-audioknihi`

Recommended adapter: generic `abs`.

## Scope

Audiobookshelf custom metadata provider for the AudioKnihi AI-generated book catalog in Belarusian.

## Deployment

The reviewed README documents a PHP script or Docker image `dexperix/abs-audioknihi:latest`, commonly served on port 8000 in its example.

ABS base URL is the script/root endpoint without `/search` supplied manually by the user.

## Hosted instance

The supplied Audiobookshelf community file listed `http://abs-audioknihi-by.dexp.in` with no auth and explicitly warned that traffic is highly limited and users should self-host if possible.
